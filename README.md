# ⚗️ Pechini & Perovskite Sol-Gel Synthesis Toolbox

An open-source scientific toolkit for laboratory stoichiometry planning, liquid alkoxide volumetric dispensing, and ICP-MS cation occupancy deconvolution for perovskite-type solid electrolytes (e.g., $\text{Li}_{0.4}\text{La}_{0.6}\text{TiO}_3$).

## 🔬 Core Capabilities
1. **Forward Engine (Laboratory Preparation):**
   - Calculates exact molar balance for hygroscopic and hydrated precursors ($\text{LiNO}_3$, $\text{La}(\text{NO}_3)_3\cdot 6\text{H}_2\text{O}$).
   - Computes density-corrected injection volume for viscous liquid alkoxides like Titanium(IV) butoxide ($\text{Ti}(\text{OBu})_4$).
   - Balances multi-dentate citric acid chelation ratios and ethylene glycol polyesterification networks.
2. **Reverse Engine (Analytical QC):**
   - Directly converts raw ICP-MS or ICP-OES elemental concentration logs (ppm or wt%) into normalized formula units ($\text{Ti} = 1.0$).
   - Identifies high-temperature lithium volatilization and A-site deficiency.
